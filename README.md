# Cobham Match Day Cards

Weekly Instagram match day cards for Cobham RFC 1st XV (Regional 2 South East).

Open the website, pick the fixture, fill in or paste the team sheet, and press **Save all four cards**.

- `data/site.json` holds the squad, fixtures, opposition clubs and settings.
- `img/` holds headshots, badges and card backgrounds.
- Fonts: Century Gothic where installed, otherwise TeX Gyre Adventor (GUST Font License), embedded in the page.
- `js/jszip.min.js` is JSZip 3.10.1 (MIT), see `js/jszip-LICENSE.md`.
